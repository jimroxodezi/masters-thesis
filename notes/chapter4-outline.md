## Principle: no hand-typed numbers

Every number, table and figure in this chapter is generated by code from the files in `results/`. A report step (proposed `python -m occupancy report`) writes LaTeX tables (`results/tables/*.tex`) and vector figures (`figures/fig4-*.pdf`), and the chapter includes them with `\input` and `\includegraphics`. Re-running the evaluation regenerates the chapter's numbers, so no value can drift from the code, and the text never repeats a number that a table holds without citing that table. The prose interpretation is written by hand, after the results exist.
